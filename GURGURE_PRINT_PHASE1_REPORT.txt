2. BUGS FOUND & FIXED (backend)
--------------------------------------------------------------------------------
1. Foreign key mismatch in print tables:
   Migrations used 'product_id' / 'group_id' columns but Eloquent inferred
   'print_product_id' / 'print_option_group_id'.
   -> Added explicit foreign keys in all relationships:
      PrintProduct::optionGroups('product_id'), priceRules('product_id')
      PrintOptionGroup::product('product_id'), options('group_id')
      PrintOption::group('group_id')
      PrintPriceRule::product('product_id')

2. "Call to undefined method PrintOption::localizeField()"
   PrintOptionGroup::toPublicArray() called $o->localizeField() which does not
   exist on PrintOption.
   -> Now uses $o->toPublicArray($lang).

3. Quantity bracket boundary bug:
   priceRules() relationship had a default ORDER BY min_qty ASC which overrode
   ->orderByDesc('min_qty'), causing qty=500 to match the 250-500 bracket (2.8)
   instead of 500-1000 (2.4).
   -> resolveUnitPrice now uses
      $product->priceRules()->get()->sortByDesc('min_qty')
   Verified: qty 500 -> 2.4, qty 499 -> 2.8.

4. order_no NOT NULL but assigned AFTER insert -> SQL error 1364.
   -> order_no is now generated BEFORE save:
      'GR-' . date('ymd') . '-' . str_pad(nextId, 4, '0')
   Verified: order GR-260908-0001 created (201 response).
